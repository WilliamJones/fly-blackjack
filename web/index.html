What is measured

Cell identities, neurotransmitter predictions, soma coordinates, and every directed connection between these 80 cells come from MaleCNS v1.0 (FlyEM / HHMI Janelia, CC BY 4.0). The body is flybody, the MuJoCo model from DeepMind and Janelia — its 68 segments and 102 hinge joints, decimated for the browser and posed by MuJoCo's own kinematics.

What is invented

The tripod gait is hand-written, as insect walking rhythm comes from the nerve cord, not the brain. Cells are leaky tanh rate units, not spiking neurons. Mapping each sensor channel onto a cell type is an engineering choice. Only the 243-parameter readout was trained; the wiring never changes.

The control that matters

Press Silence circuit. That zeroes the circuit's output and leaves everything else — the same trained weights, the same gait, the same body. If the fly still behaved, the connectome would be decoration. Watch it stop steering.
